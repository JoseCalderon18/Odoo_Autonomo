Autonomo Quotes
===============

Modulo para presupuestos avanzados de autonomos.

Uso principal:

- Entrar en Ventas > Presupuestos.
- Abrir o crear un presupuesto.
- Ir a la pestana Costes y kilometraje.
- Seleccionar plantilla, tarifa de desplazamiento, horas, kilometros, combustible, peajes, parking, dietas y costes.
- Guardar version antes de modificar un presupuesto enviado.

Menus propios:

- Autonomo > Presupuestos > Plantillas
- Autonomo > Presupuestos > Tarifas de desplazamiento
- Autonomo > Presupuestos > Conceptos de coste

Este modulo no sustituye la factura ni los libros fiscales. La factura sigue siendo account.move.
